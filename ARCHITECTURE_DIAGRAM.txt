║                            KEY DESIGN PATTERNS                                ║
╚══════════════════════════════════════════════════════════════════════════════╝

1. Observer Pattern:
   ClipboardMonitor → callbacks → event handlers

2. Service Layer:
   Components → Services → API

3. Caching Strategy:
   API Request → Check Cache → Hit/Miss → Update Cache

4. Rate Limiting:
   Request Queue → 1 sec delay → Execute → Next

5. IPC Communication:
   Renderer ↔ Main Process ↔ Services
